# Doodle Road Workshop

Полноценная офлайн-игра для Windows: рисуйте дорогу, собирайте машинку из деталей и довозите её до финиша.

## Что есть в игре

- 200 процедурно генерируемых уровней с повторной случайной генерацией
- три сложности: легко, нормально и сложно
- свободное рисование дорог и прямых деревянных балок
- конструктор в духе vehicle-puzzle: дополнительные колёса, воздушные шары и ракеты
- камни, ящики, шипы, движущиеся пилы, грязь, ветер и разрушаемые стены
- топливо, повреждения, монеты, рейтинг до трёх звёзд
- гараж: цвета, кузова, колёса и следы
- процедурные звуковые эффекты без внешних файлов
- полноэкранный режим F11
- полностью автономный self-contained Windows x64 EXE

Сохранение создаётся как `save.json` в той же папке, где находится `DoodleRoadWorkshop.exe`.

## Управление

- мышь — строить и выбирать
- колесо мыши / A и D — двигать камеру в мастерской
- стрелки / WASD — газ и тормоз
- пробел — ракеты
- R — назад в мастерскую
- Esc — пауза
- M — звук
- F11 — полноэкранный режим
